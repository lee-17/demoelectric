# Electric Company CMV — Tutorial Applied

Applied from the provided tutorial:
- Home, About, Services, Contact, and Register controllers/views
- Routes for all tutorial pages
- `User` model with validation, timestamps, and password hashing callback
- Bootstrap/Font Awesome layout and custom CSS/JS assets
- MySQL database configuration for `electriccompany`
- `electriccompany.sql` database/table setup

## Run
1. Start Apache and MySQL in XAMPP.
2. Import `electriccompany.sql` into phpMyAdmin.
3. Put this project in your XAMPP web root.
4. Open the project through CodeIgniter's configured local URL.
5. The tutorial's expected database credentials are MySQL user `root` with no password and database `electriccompany`.
